Method and limits

  • All eight sources were selected before inference. All outputs are included, including errors in both engines. No translations were corrected, retries tuned or currency/name substitutions applied after inference.
  • Identical manually selected sentences or clauses were sent independently to each engine. The Turkish incentive case also includes one table row. This is not a full-document or automatic-extraction benchmark.
  • The current translator kept its existing pipeline: Argos model, company-name protection and Portuguese legal glossary. Company-name arguments use saved record names; the Vietnamese cases use the watchlist name. Thus this compares prospective pipelines, not bare models.
  • MADLAD used the pinned Google-hosted checkpoint already downloaded and hash-verified, converted to CTranslate2 INT8; CPU, four threads, beam size four. Sources fitted within model limits. Fallback model downloads were disabled for the existing translator.
  • Inference was offline and sequential. Public web sources were read for sample selection; no GNews or TheNewsAPI requests were made. The live app, its translation configuration and database were not changed.
  • Numbers surviving unchanged does not prove meaning survived. Review currencies, direction of debt, conditional wording, names and event attribution against the original source. These checks do not verify that a publisher’s factual claims are true.
  • The original text is accessible through the publisher links. The excerpts are intentionally short; long-article omissions, extraction reliability and downstream risk scoring require separate validation.
