Simplified translation reviewer: Qwen and Gemma retest

Evaluation series started 4 November 2026; simplified retest continued 5 November. App, translator, database and live scoring unchanged. Unresolved cases are automatically withheld in the experiment; no analyst foreign-language approval step is introduced.

Previous reasoning comparison · Counts and run identities

Result and recommendation

Prefer Gemma with reasoning for the next isolated reviewer trial; keep the existing translator and app unchanged. Both reasoning-on configurations returned valid results for all 46 cases and flagged 18 of 19 provisionally labelled material errors. Gemma rejected one of 70 previously nonmaterial candidates versus five for Qwen, and completed in 38.39 minutes versus 44.30. These are small-sample operational results, not established production accuracy.

Qwen reasoning-on failures fell from 20 to zero; Gemma reasoning-on failures fell from two to zero. This supports the diagnosis that the old response protocol was a major obstacle for Qwen. The change is not a universal improvement: Qwen off regressed from zero to six failed cases, partly because of new protocol restrictions. Gemma off improved from 28 failures to seven, but still approved three labelled errors. Neither new reasoning-off configuration is the preferred reviewer.

Remaining semantic limitations: both reasoning models still approve the disputed NLLB covenant wording. Gemma now also accepts the real Portuguese candidate whose possibility/timing nuance it flagged in the previous run. That earlier real-source advantage is no longer stable under the simpler prompt, even though both models catch the more explicit error in the short Portuguese regression sentence. No labelled-bad candidate is selected by this experiment, but NLLB is excluded from selection and publisher examples lie outside the nineteen-error metric; this is not proof of safe automatic approval.

Gemma makes fewer questionable rewrites in these examples: it retains MADLAD for the Greek borrowing/lending article, whereas Qwen additionally objects to singular versus plural dividends and rewrites it. Gemma also accepts the clean Portuguese and Turkish regression paraphrases that Qwen rejects. Both propose separately checked corrections for invented Vietnamese currencies; the second check uses the same model and is not independent verification.

Next: retain the compact verdict-and-evidence design, separate optional correction output and harmless duplicate evidence from substantive judgment failures, and evaluate fresh articles against independently established meanings before enabling automatic correction. Preserve automatic withholding for unresolved meaning. Date/number formatting checks still cause some unnecessary withholding and need their own controlled follow-up.

Each configuration uses the same 46 cases and 105 candidate translations. Nineteen candidates have provisional material-error labels. The twelve formerly fresh fictional cases are now regression examples, not a new held-out test. Labels are assistant judgments; this is not an estimate of production accuracy.

What changed

The response now contains one candidate verdict and a list of material issues. The nested seven-category coverage grid and wording-only issue reports are removed. The prompt still asks the model to check all seven dimensions. Uncertain results remain ineligible; corrections are permitted only when every candidate is rejected for a material error and still receive a separate same-model check.

Evidence uses arrays of separate contiguous quotations. Validation preserves offsets into original text, allowing one-layer HTML entity decoding, NFC accent composition, typographic quotation marks and whitespace changes. It does not change words, case, numbers, currencies or negation; invent ellipses; or accept word fragments inside a different word. Invalid JSON and unsupported verdicts remain failures. Number/date routing diagnostics are unchanged to avoid confounding this retest.

Settings remain temperature 0, seed 42, 32768 context, 8192 output tokens, medium reasoning on versus none off, and unconstrained final JSON. Reasoning-on success requires observed reasoning tokens and a separate final answer. No retries or per-case prompt tuning. This compares a changed prompt/protocol and evidence handling together, not a pure evidence-normalization ablation.

Installed configurations: Qwen 27B uses MLX 5-bit weights; Gemma 31B uses GGUF Q4_0 QAT weights. Timings describe these local configurations, include correction checks and are not a hardware-normalized comparison of model families. Each configuration was run once.
