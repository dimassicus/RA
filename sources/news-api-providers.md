# GNews and TheNewsAPI in RA

Checked **4 November 2026**. Both are now optional Python source adapters in the search worker. The API keys stay in the local `.env` file or process environment; the browser never receives them. RA stores publisher article links, headlines, dates, language and discovery service, then keeps its normal analyst review step. An API match is a lead, not confirmation that the article concerns the exact legal entity.

| Provider | Free tier | First paid tier | Access and caveats |
| --- | --- | --- | --- |
| [GNews Search API](https://docs.gnews.io/endpoints/search-endpoint) | [100 requests/day; up to 10 articles/request; 12-hour delay; 30-day history](https://gnews.io/pricing). | [Essential €49.99/month](https://gnews.io/pricing): 1,000 requests/day, up to 25 articles/request, real-time. | Free access is for development, evaluation and other non-commercial use; business production needs an active paid plan. GNews also offers an [official MCP server](https://docs.gnews.io/mcp-server), but RA uses REST to avoid an AI tool call for each search. |
| [TheNewsAPI All News](https://www.thenewsapi.com/documentation) | [100 requests/day; up to 3 articles/request](https://www.thenewsapi.com/pricing). | [Basic $19/month](https://www.thenewsapi.com/pricing), or $16/month with annual billing: 2,500 requests/day and up to 25 articles/request. | Search supports exact phrases and all available languages. Confirm your subscription's commercial-use and redistribution terms before production use. |

RA makes **one exact legal-name query per selected provider per company** over a seven-day window, without restricting article language or publisher country. This captures multilingual and cross-border coverage. Each provider has a configurable **95-request daily cap** by default, recorded in PostgreSQL against the UTC date. For a watchlist of at most 95 companies, RA tries both providers for each company. For larger lists it allocates companies across the providers and rotates the order across days. A 200-company run with both free tiers can cover at most 190 companies via these APIs at the conservative caps; Google News RSS still runs for every company. Two full runs in one UTC day share the same budget. The free plans' 10/3 article limits mean this is discovery coverage, not exhaustive media monitoring.

If a provider fails, RA records a source error without printing the key or request URL, and the other news sources continue. A missing key silently disables that provider; the dashboard reports whether each key is configured. See the root [README](../README.md#news-api-keys) for local setup.

TheNewsAPI requires `published_after` as a UTC timestamp without a timezone suffix; GNews uses the ISO timestamp with `Z`. A bounded live check on 4 November accepted one request per provider, with no source errors and no exact-name articles returned. Provider error payloads are treated as failures, and raw response errors are never shown because they may echo credentials.
