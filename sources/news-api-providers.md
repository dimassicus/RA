# GNews and TheNewsAPI in RA

Checked **4 November 2026**. Both are now optional Python source adapters in the search worker. The API keys stay in the local `.env` file or process environment; the browser never receives them. RA stores publisher article links, headlines, dates, language and discovery service, then keeps its normal analyst review step. An API match is a lead, not confirmation that the article concerns the exact legal entity.

Updated **10 November 2026**: RA combines reviewed aliases, short names and legal names using exact phrases and each provider's OR syntax. Short ambiguous names require country context, including native and English country names. Query groups split at the query-length limit, and each group's first page is tried before deeper pages. Every request retains the selected date bounds, without restricting article language or publisher country.

GNews uses 10 articles per page; TheNewsAPI uses the account's default page size. Pagination follows provider result counts and page limits, deduplicates URLs, and stops on repeated pages. Each provider retains its configurable **95-request daily cap**, tracked in PostgreSQL against the UTC date. Remaining requests are divided across companies; scarce coverage rotates across runs. All runs share these daily budgets. Results already fetched survive later-page failures, and budget or pagination limits appear as incomplete-coverage errors. Logs record provider, run, query, page and returned/retained counts without credentials. Account history and result ceilings still apply; this remains discovery coverage, not exhaustive media monitoring.

If a provider fails, RA records a source error without printing the key or request URL, and the other news sources continue. A missing key silently disables that provider; the dashboard reports whether each key is configured. See the root [README](../README.md#news-api-keys) for local setup.

TheNewsAPI requires `published_after` as a UTC timestamp without a timezone suffix; GNews uses the ISO timestamp with `Z`. A bounded live check on 4 November accepted one request per provider, with no source errors and no exact-name articles returned. Provider error payloads are treated as failures, and raw response errors are never shown because they may echo credentials.
