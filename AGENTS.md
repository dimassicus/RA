# Git workflow

After completing and testing a requested change, commit the files and hunks for that task and push the current branch to its GitHub remote. Leave unrelated work in the working tree. Follow any different instructions the user gives for a specific task.

# Repeat watchlist searches

Search the full requested publication window on every run so previously missed stories can still surface. For the same company, reuse completed translations and source checks when their inputs are unchanged. Check publisher content and attachments for revisions. Keep each run’s lead and selection history separate.
