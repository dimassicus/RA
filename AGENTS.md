# Git workflow

After completing and testing a requested change, commit the files and hunks for that task and push the current branch to its GitHub remote. Leave unrelated work in the working tree. Follow any different instructions the user gives for a specific task.

# Repeat watchlist searches

Keep Perplexity on the full requested window for every watchlist batch. For Google News RSS, request only uncovered publication intervals for each company query and edition, including gaps within a day. Apply the same rule to shared country and sector RSS queries. Preserve failed and deferred intervals for retry. Other providers keep their normal windows. For the same company, reuse completed translations and source checks when their inputs are unchanged. Check publisher content and attachments for revisions. Keep each run’s lead and selection history separate.
